# Contact Book Using Dictionaries

## Description

A simple command-line contact book built using Python dictionaries. It allows users to manage contact information through an easy-to-use menu.

## Features

- Add new contacts
- Search contacts by phone number
- Update existing contacts
- Delete contacts
- View all saved contacts
- Prevent duplicate phone numbers
- Handle contacts that do not exist

## Technologies Used

- Python
- Dictionaries
- Loops and conditional statements

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
 contactbook.py
```
